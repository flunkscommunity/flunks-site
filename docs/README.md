# Flunks Site Documentation

This directory contains organized documentation for the Flunks project.

## Directory Structure

### `/fixes/` - Bug Fixes & Problem Solutions
Documentation for bug fixes, issues resolved, and troubleshooting guides.
- Chat system fixes
- Wallet connection fixes
- Mobile responsive fixes
- UI/UX bug fixes

### `/features/` - Feature Documentation
Guides for major features and systems implemented in the project.
- Access control system
- Gum economy system
- Profile system
- Game mechanics
- Paradise Motel system

### `/guides/` - Implementation Guides
Step-by-step guides for developers working on the project.
- Deployment guides
- Development setup
- Testing guides
- Integration guides

### `/database/` - Database Scripts
SQL scripts for database setup, migrations, and data management.
- Table creation scripts
- Migration scripts
- Data verification queries
- Testing utilities

## File Organization Tips

- Fix documentation uses past tense (e.g., "CHAT_FIX.md")
- Feature docs describe current state (e.g., "GUM_SYSTEM.md")
- Guides are action-oriented (e.g., "DEPLOYMENT_GUIDE.md")
- SQL files are grouped by purpose in `/database/`
