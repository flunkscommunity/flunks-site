# 📱 Flunks Wallet Setup Guide - Android

**Get connected in 3 easy steps!**

---

## 🎯 What You Need

1. **Flunks App** - You're here! ✅
2. **Flow Wallet** - Download from Play Store (free)
3. **5 minutes** - That's all it takes!

---

## 📥 Step 1: Install Flow Wallet

### Option A: Flow Wallet (Recommended ⭐)

1. Open **Google Play Store**
2. Search for **"Flow Wallet"** or **"Lilico"**
3. Install the app (look for the official Flow Foundation app)
4. Open Flow Wallet and follow the setup wizard

**Direct Link:** [Flow Wallet on Play Store](https://play.google.com/store/apps/details?id=io.outblock.lilico)

### Option B: Blocto Wallet

1. Open **Google Play Store**
2. Search for **"Blocto"**
3. Install and set up

### Option C: Dapper Wallet (No App Needed!)

Dapper works entirely in your browser - no separate app required!

---

## 🔐 Step 2: Set Up Your Wallet

### First Time User?

**Creating a new wallet:**
1. Open Flow Wallet app
2. Tap **"Create New Wallet"**
3. **Write down your recovery phrase** (12-24 words)
   - ⚠️ **CRITICAL:** Store this safely! It's the ONLY way to recover your wallet
   - Never share it with anyone
   - Keep it offline (write on paper)
4. Verify your recovery phrase
5. Set a PIN or biometric lock
6. Done! Your wallet is ready

**Already have a Flow wallet?**
1. Open Flow Wallet app
2. Tap **"Import Wallet"**
3. Enter your recovery phrase
4. Set a PIN or biometric lock

### Optional: Add Funds

To interact fully with Flunks (claim NFTs, transactions), you'll need a small amount of FLOW:
- **For testing:** Use Flow testnet faucet (free FLOW)
- **For real use:** Purchase FLOW from an exchange (Coinbase, Kraken, etc.)
- **Amount needed:** 0.001 FLOW is enough to start (~$0.01)

---

## 🔗 Step 3: Connect to Flunks

Now the fun part! Let's link your wallet to Flunks:

### On Flunks App:

1. **Open Flunks app** (this app!)
2. Tap the **"Connect Wallet"** or **"Account"** button
3. Select **"Flow Wallet"** from the list
4. **Flow Wallet app will open automatically** 
   - If it doesn't open: 
     - Make sure Flow Wallet is installed
     - Try tapping "Connect" again
     - Restart Flunks and try once more

### In Flow Wallet App:

5. **Review the connection request**
   - App name: "Flunks"
   - Logo: Flunks logo
   - Permissions: View wallet address, request transactions
6. Tap **"Approve"** or **"Connect"**
7. **You'll automatically return to Flunks**

### Back in Flunks:

8. **You're connected!** 🎉
   - You'll see your wallet address (e.g., `0x1234...`)
   - Your NFT collection will load
   - You can now interact with the app

## ✅ How to Know It Worked

You're successfully connected when you see:
- ✅ Your wallet address displayed in the app
- ✅ "Connected" or green checkmark icon
- ✅ Your Flow NFTs loading
- ✅ No more "Connect Wallet" prompts

## 🔄 Do I Need to Reconnect Every Time?

**No!** Once connected, you should stay logged in:
- Closing Flunks → **Still connected** when you reopen
- Restarting your phone → **Still connected**
- App updates → **Usually still connected**

You only need to reconnect if:
- You disconnect manually
- You clear app data
- You reinstall Flunks
- You switch wallets

## 🚨 Troubleshooting

### "Flow Wallet Won't Open"

**Problem:** Tapping "Connect Wallet" does nothing

**Solutions:**
1. ✅ **Check Flow Wallet is installed**
   - Open Play Store, search "Flow Wallet"
   - Is it installed? If not, install it
   
2. ✅ **Try these steps:**
   - Close both apps completely (swipe away from recent apps)
   - Open Flow Wallet first (just to verify it works)
   - Close Flow Wallet
   - Open Flunks and try connecting again
   
3. ✅ **Update both apps:**
   - Check Play Store for Flunks updates
   - Check Play Store for Flow Wallet updates
   - Restart phone after updating

4. ✅ **Clear Flunks cache:**
   - Android Settings → Apps → Flunks
   - Tap "Storage"
   - Tap "Clear Cache" (NOT "Clear Data" - that logs you out)

### "Stuck on 'Connecting...'"

**Problem:** Spinner just keeps going

**Solutions:**
1. ✅ **Check internet connection**
   - Switch between WiFi and mobile data
   - Try a different network
   
2. ✅ **Wait 30 seconds, then try again**
   - Sometimes it just takes a moment
   
3. ✅ **Force close and restart:**
   - Close Flunks completely
   - Clear from recent apps
   - Reopen and try again

### "Connected but Nothing Loads"

**Problem:** Shows connected but NFTs don't appear

**Solutions:**
1. ✅ **Pull to refresh:**
   - Swipe down on the screen to refresh
   
2. ✅ **Check wallet has FLOW:**
   - Open Flow Wallet app
   - Check balance (need at least 0.001 FLOW)
   - If empty, get FLOW from faucet or exchange
   
3. ✅ **Reconnect wallet:**
   - In Flunks, tap "Disconnect"
   - Wait 5 seconds
   - Tap "Connect Wallet" again

### "Permission Denied" or "Request Failed"

**Problem:** Flow Wallet shows error when trying to connect

**Solutions:**
1. ✅ **Update Flow Wallet:**
   - Older versions may have compatibility issues
   
2. ✅ **Check wallet is on Mainnet:**
   - Open Flow Wallet settings
   - Verify network is "Mainnet" not "Testnet"
   
3. ✅ **Try different wallet:**
   - Dapper works in browser (no app)
   - Blocto is another alternative

### "Need to Reconnect Every Time"

**Problem:** Connection doesn't persist between app opens

**Solutions:**
1. ✅ **Don't force close apps:**
   - Let Android manage app lifecycle
   - Constantly force-closing can clear sessions
   
2. ✅ **Check battery optimization:**
   - Settings → Battery → Battery Optimization
   - Find Flunks → Set to "Don't optimize"
   - This prevents Android from killing the app's background state
   
3. ✅ **Grant all permissions:**
   - Settings → Apps → Flunks → Permissions
   - Make sure all required permissions are granted

## 🎓 Understanding Wallet Security

### Your Recovery Phrase is Everything

- **Recovery phrase = Full wallet access**
- If someone gets it, they can steal everything
- If you lose it, your wallet is gone forever
- **Flunks will NEVER ask for your recovery phrase**

### What's Safe to Share?

✅ **Safe:**
- Your wallet address (e.g., `0x1234abcd...`)
- Public transaction hashes
- Your username/profile

❌ **NEVER share:**
- Recovery phrase (12-24 words)
- Private keys
- Wallet password/PIN
- Signing keys

### Approving Transactions

When Flunks requests a transaction, you'll see:
- What's happening (e.g., "Claim Daily Reward")
- What it costs (e.g., "0.001 FLOW")
- Your approval is required

**Tips:**
- Read what you're approving
- Check the amount/action
- If unsure, decline and ask support
- Flunks transactions usually cost <0.01 FLOW
