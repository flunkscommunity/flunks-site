# MyPlace Profile Songs

Upload the music files for each clique in this directory with the following naming convention:

## File Names:
- `geek.mp3` - For the Geeks clique profile
- `freak.mp3` - For the Freaks clique profile  
- `jock.mp3` - For the Jocks clique profile
- `prep.mp3` - For the Preps clique profile

## Recommended Songs by Clique:

### Geeks (TechNerd profile)
- "The Humpty Dance" by Digital Underground
- "Mr. Roboto" by Styx
- "Computer Love" by Kraftwerk
- Anything by Weird Al Yankovic

### Freaks (RebelSoul profile)  
- "Smells Like Teen Spirit" by Nirvana
- "Paranoid" by Black Sabbath
- "Anarchy in the U.K." by Sex Pistols
- "Break Stuff" by Limp Bizkit

### Jocks (ChampAthlete profile)
- "Eye of the Tiger" by Survivor
- "We Will Rock You" by Queen
- "Pump It Up" by Elvis Costello
- "Welcome to the Jungle" by Guns N' Roses

### Preps (PopularKid profile)
- "I Want It That Way" by Backstreet Boys
- "...Baby One More Time" by Britney Spears
- "Tearin' Up My Heart" by *NSYNC
- "Kiss Me" by Sixpence None The Richer

## File Format:
- Use MP3 format for best compatibility
- Keep file sizes reasonable (under 5MB each)
- Sample rate: 44.1kHz or 48kHz recommended

The music player will automatically load the appropriate song for each clique profile!
